# chat-kit: צ'אט צף בעברית (RTL) לאתר משרד עורכי דין

רכיב צ'אט מוכן להעתקה לכל פרויקט Next.js. הכול חינמי וקוד פתוח, ללא מנוי, ללא מפתח API וללא שרת: הקול, הזיהוי והתשובות רצים בדפדפן של המבקר.

## מה בפנים

| רכיב | מה הוא עושה |
|---|---|
| כפתור צ'אט צף | בפינה (בצד ה"סוף" של העמוד: שמאל בעברית), נפתח לחלון עם `Esc` לסגירה |
| חלון אווטאר בראש הצ'אט | תמונה, וידאו מקומי (`webm`/`mp4`) שזז בזמן הדיבור, בקרות הפעלה/עצירה/השתקה, כתוביות מסונכרנות ותמלול מלא |
| הודעות | אזור גלילה נגיש (`role="log"`), מחוון "כותבת…", כפתור "הקראה בקול" לכל תשובה |
| שאלות מוכנות | כפתורי לחיצה מהירה, נבנים מהשאלות ששמת `quickReply: true` |
| קלט | הקלדה, או מיקרופון (Web Speech API). מי שדיבר מקבל תשובה בקול |
| קול | הקלטה מוכנה אם יש, ואם לא: הקול העברי הטוב ביותר שהמכשיר מציע, משפט אחרי משפט, בקצב רגוע |
| התאמת תשובות | מנוע מילות מפתח בעברית (מתעלם מניקוד ומקידומות כמו ה/ב/ל/ש), בלי שרת ובלי מודל שפה |
| חירום | מילים כמו "מעצר" או "חקירה" מוסיפות הודעה דחופה עם כפתור חיוג |
| עמידות | שגיאה בצ'אט לא מפילה את האתר (Error Boundary). בלי קול או בלי מיקרופון, הצ'אט ממשיך לעבוד בכתב |

## דרישות

- Next.js (App Router) ו-React 18 ומעלה. נבדק על Next.js 16 ו-React 19
- Tailwind CSS 4 (הרכיב משתמש במחלקות Tailwind בלבד, כולל תכונות לוגיות `start`/`end` ל-RTL)
- אין חבילות נוספות

## התקנה בפרויקט חדש (5 דקות)

1. העתיקו את התיקייה `chat-kit/` לשורש הפרויקט (או ל-`src/`).
2. ודאו ש-Tailwind סורק אותה. ב-Tailwind 4 מספיק שהתיקייה בתוך הפרויקט. ב-Tailwind 3 הוסיפו אותה ל-`content` ב-`tailwind.config`.
3. בקובץ `app/layout.tsx` הוסיפו (ראו `example/layout.example.tsx`):

   ```tsx
   import { ChatWidget } from '@/chat-kit/src';
   import { chatConfig } from '@/chat-kit/chat.config';

   // בתוך <body>, אחרי {children}:
   <ChatWidget config={chatConfig} />
   ```

4. הריצו `npm run dev` ופתחו את האתר. הצ'אט ייפתח לבד אחרי 4 שניות (שנו ב-`autoOpenAfterMs`, `0` = לא נפתח לבד).

## התאמה ללקוח חדש: רק קובץ אחד

כל התוכן נמצא ב-`chat-kit/chat.config.ts`:

- `assistantName`, `firmName`, `tagline`: השם של העוזרת והמשרד. השם נקבע כאן בלבד, בשום קומפוננטה.
- `welcome.message`: ההודעה הראשונה.
- `knowledge`: הנושאים. לכל נושא: `question`, `keywords`, `answer`, ואופציונלית `links`, `audio`, `quickReply`.
- `urgent`: מילים שמציגות הודעת חירום.
- `fallback`: מה אומרים כשלא הובנה השאלה.
- `pronunciations`: איך לאיית לקול מילים שהוא מקריא לא נכון.
- `labels`: כל הכיתובים בממשק.

כתבו כל תשובה בלשון "אני עוזרת וירטואלית, לא עורכת דין". את התוכן המשפטי חייב לאשר עורך הדין לפני העלאה.

### איך המנוע בוחר תשובה

- ביטוי שלם מתוך `keywords` שמופיע בהודעה (`"שכר טרחה"`) שווה יותר ממילה בודדת.
- מילה בודדת נמצאת גם עם קידומת: `"בגירושין"` מוצאת `"גירושין"`.
- אם לשאלה אין התאמה טובה, נשמעת ה-`fallback` ונקראת `onUnanswered(question)` (אם הגדרתם אותה), כך שתדעו מה חסר בידע. אפשר לשלוח אותה לכל מקום או להתעלם.
- טיפ: הוסיפו 6 עד 12 מילות מפתח לכל נושא, בכל הניסוחים שאנשים כותבים.

## קול: הכול חינמי

הדפדפן מקריא כל תשובה בקול העברי הטוב ביותר שבמכשיר:

- Edge ו-Windows: קולות "Natural" (למשל Hila). הכי טבעיים.
- Chrome: "Google עברית". Safari: Carmit.
- קולות בסיסיים שמובנים במכשיר נשמעים רובוטיים. אפשר לעקוף אותם בהקלטות (למטה).

### הגייה נכונה של מילים לועזיות

הקול קורא "צ'אט" כ"צאט". הפתרון: ב-`pronunciations` ממפים את הכתיב לכתיב שהקול קורא נכון:

```ts
pronunciations: { "צ'אט": 'טשאט', 'צ׳אט': 'טשאט' }
```

המיפוי חל רק על הקול, לא על מה שמופיע במסך. הוסיפו כל מילה שהקול מקריא לא טוב. אפשר להשתמש גם בניקוד.

### הקלטות משלכם (הכי אנושי, חינמי)

1. הקליטו, או הפיקו עם כלי קוד פתוח או חינמי, קובץ שמע לתשובה. פורמט `webm` או `mp3` (`opus` ב-`webm` קטן וטוב).
2. שימו אותו ב-`public/chat-kit/`, למשל `public/chat-kit/part-01.webm`.
3. ב-`chat.config.ts`: `audio: '/chat-kit/part-01.webm'` על הנושא. ההקלטה תנוגן במקום הקול של הדפדפן, ואם נכשלה, הדפדפן ימשיך לבד.
4. הקפידו על קול אחד בכל הקבצים, בלי רעשי רקע, ובקצב רגוע. הקלטה של אדם אמיתי מותרת רק בהסכמתו.

## האווטאר: `AvatarVideoPlayer`

החלון שבראש הצ'אט. כל הקבצים מקומיים ב-`public/`, בלי שירות חיצוני. ב-`welcome` (כל השדות אופציונליים):

```ts
welcome: {
  message: '...',
  poster: '/chat-kit/assistant.webp',                              // תמונה: תמיד מוצגת, וגיבוי אם הוידאו נכשל
  video: [{ src: '/chat-kit/assistant.webm', type: 'video/webm' },
          { src: '/chat-kit/assistant.mp4',  type: 'video/mp4' }],  // סרטון קצר של האווטאר
  videoHasSound: false,                                            // true אם הקול נמצא בתוך הסרטון עצמו
  audio: '/chat-kit/part-01.webm',                                 // הקלטת הפתיחה (כשהסרטון אילם)
  captions: [{ start: 0, text: 'שלום, ברוכים הבאים.' }],           // כתוביות לפי שנייה
}
```

### איך הסרטון מתנהג

- **סרטון אילם בלולאה** (`videoHasSound: false`, ברירת המחדל): הוא זז כשהעוזרת מדברת, כלומר בזמן הקלטת הפתיחה ובזמן הקראת כל תשובה (בהקלטה או בקול הדפדפן), ועוצר על הפריים הראשון כשהיא שותקת. מי שביקש פחות תנועה בהגדרות המכשיר רואה תמונה נייחת.
- **סרטון מדבר** (`videoHasSound: true`): הקול נמצא בתוך הקובץ. הוא מתנגן פעם אחת בלחיצה על "הפעלה", בלי לולאה ובלי קשר לתשובות.
- **בקרות:** הפעלה והשהיה, עצירה (מפסיקה גם את קול הדפדפן) והשתקה. הכול נגיש במקלדת, עם יעדי לחיצה של 44px.
- **גיבוי:** אם הקובץ לא נטען, נשארת התמונה. בלי `poster`, `video` ו-`audio` החלון נעלם והצ'אט הוא רק ההודעות.
- **קול דפדפן כגיבוי חינמי:** כל תשובה שאין לה `audio` מוקראת ב-Web Speech API. הסרטון זז גם אז.

### איך מכינים סרטון אווטאר בכלים חינמיים

1. הפיקו סרטון קצר (5 עד 10 שניות, בלי קול, בלי עיוותים) עם כלי קוד פתוח לאנימציית פנים כמו LivePortrait, או צלמו סרטון של אדם שהסכים לכך. הכלים האלה דורשים כרטיס מסך או הרבה זמן עיבוד, ואיכות התוצאה משתנה. בדקו תמיד את הסרטון לפני העלאה, ואל תשתמשו בפנים או בקול של אדם בלי הסכמתו.
2. כווצו עם ffmpeg (חינמי):

   ```bash
   ffmpeg -i avatar.mp4 -an -vf scale=640:-2,fps=24 -c:v libvpx-vp9 -b:v 600k -pix_fmt yuv420p public/chat-kit/assistant.webm
   ffmpeg -i avatar.mp4 -an -vf scale=640:-2,fps=24 -c:v libx264 -profile:v baseline -level 3.1 -pix_fmt yuv420p -movflags +faststart -crf 28 public/chat-kit/assistant.mp4
   ```

   ה-`mp4` בפרופיל baseline מתנגן בכל טלפון ומחשב, ו-`webm` קטן יותר בדפדפנים מודרניים. שימו את שניהם. מומלץ מתחת ל-3MB.
3. תמונה: `ffmpeg -i avatar.mp4 -frames:v 1 -vf scale=640:-2 public/chat-kit/assistant.webp`.
4. הקלטת פתיחה (אופציונלי): `ffmpeg -i welcome.wav -c:a libopus -b:a 32k public/chat-kit/part-01.webm`, והוסיפו `captions` באותם זמנים.
5. אם הסרטון לא נראה טבעי, השאירו רק `poster`. תמונה נקייה עם קול טוב עדיפה על תנועה לא טבעית.

## נגישות

כפתורים בגודל 44px לפחות, תוויות לכל הפקדים, `Esc` סוגר, פוקוס מחזור לכפתור הפתיחה, `aria-live` להודעות חדשות, מצב "פחות תנועה" מבטל את ההשהיה המלאכותית של "כותבת…", וכל הצבעים בניגודיות גבוהה. בדקו שוב אחרי שינוי צבעים.

## פריסה חינמית

האתר הוא Next.js רגיל, לכן: חברו את ה-repo ל-Netlify או ל-Vercel (תוכנית חינמית), ללא משתני סביבה. הצ'אט אינו שולח כלום החוצה. אם תחברו `onUnanswered` לשירות חיצוני, עדכנו את מדיניות הפרטיות.

## בדיקות מהירות לפני העלאה

- Chrome ו-Safari בטלפון: הפתיחה, הקלדה, כפתור "הקראה בקול".
- Firefox: הצ'אט עובד בכתב. כפתור המיקרופון נעלם, כי זיהוי דיבור לא נתמך שם.
- אייפון: הקול מתחיל רק אחרי מגע ראשון. הרכיב מטפל בכך בעצמו כשלוחצים על שליחה, מיקרופון או שאלה מוכנה.
- נסו: "איך קובעים פגישה", "כמה זה עולה", "נעצרתי", ושאלה שלא קשורה, ובדקו את התשובה האחרונה (fallback).

## מגבלות (כדאי לדעת)

- זה מנוע מילות מפתח, לא מודל שפה: הוא עונה רק על מה שכתבתם. לשיחה חופשית יש לחבר מודל (אפשר לשלב Gemini או Claude בשרת בנפרד); הרכיב לא תלוי בזה.
- איכות הקול של הדפדפן משתנה בין מכשירים. להקלטות אחידות השתמשו ב-`audio`.
- זיהוי הדיבור דורש חיבור לאינטרנט בחלק מהדפדפנים, כי הדפדפן שולח את השמע לשירות הזיהוי שלו.
