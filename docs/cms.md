# ניהול תוכן עם Sanity

האתר מחובר ל־Sanity (פרויקט `pqddwskg`, dataset `production`, מוגדרים ב־`brand.cms` בקובץ `src/lib/brand.ts`).
ממשק העריכה נמצא באתר עצמו, בכתובת **`/studio`**, בצבעים ובגופנים של האתר (הצבעים נלקחים מ־`brand.colors`).

## מה אפשר לערוך
| סוג | איפה מופיע באתר |
| --- | --- |
| שאלה נפוצה | עמוד הבית (7 הראשונות), `/faq`, דף הנחיתה `/consultation`, נתוני FAQ לחיפוש ו־`llms-full.txt` |
| המלצה | אזור ההמלצות (ממוינות מהחדשה לישנה לפי התאריך) |
| כתבה בתקשורת | "כתבות וראיונות" בעמוד המדריכים |
| הגדרות האתר | שם המשרד, פרטי קשר, צבעי האתר, פתיחת העמוד, אודות, "איך זה עובד", "למה אנחנו", פס הנתונים, הצ׳אט (שם, ברכה, שאלות מוצעות), כותרת ותיאור לגוגל |
| תחום עיסוק | כרטיסים בעמוד הבית, עמוד התחום, קישורי הניווט, הצ׳אט |
| מדריך | `/articles`, עמוד המדריך, הכרטיסים בעמוד הבית ובתחומי העיסוק, מפת האתר, RSS, `llms.txt`, ושאלות המדריכים ב-`/faq` |
| סרטון המלצה | "לקוחות מספרים" בעמוד הבית |

מה שנשאר בקוד (`brand.ts`): וידאו הפתיחה ומסגור המדיה, הלוגו והגופנים, גלריית התמונות והתעודות באודות, מכתבי התודה הסרוקים, העמודים המשפטיים (פרטיות, תנאי שימוש, נגישות), והתשובות הקבועות של הצ׳אט (ב-`knowledge.ts`; פרטי הקשר שבהן מתעדכנים אוטומטית).
**הצ׳אט** עונה מאותו תוכן חי: שאלות נפוצות ומדריכים שנערכים ב-Studio נכנסים גם לתשובות המקומיות וגם להנחיות של מודל השפה, תוך דקה. המשפטים שהוקלטו בקול של ליאור נשארים רק למשפטים שלא השתנו. תשובה שנוסחה מחדש תושמע בקול הדפדפן עד שתוקלט.

**מדריך חדש:** מדריך שפורסם אחרי הבנייה האחרונה נבנה בביקור הראשון בו, ומופיע בכל הרשימות תוך דקה.
כתובת העמוד (slug) לא משנים אחרי פרסום. **סרטון:** סרטון יוטיוב אפשר להוסיף לבד. קובץ וידאו מקומי דורש קודם להעלות את הקובץ ואת תמונת השער לתיקיית `public/videos` בקוד.

## איך נכנסים
1. נכנסים ל־`https://<האתר>/studio`.
2. מתחברים עם חשבון Sanity (Google / GitHub / אימייל). פעם ראשונה: מוסיפים את העורך כחבר בפרויקט
   ב־sanity.io/manage → הפרויקט → Members.
3. עורכים, לוחצים **Publish**. השינוי מופיע באתר תוך דקה.

## איך זה בנוי (ועמיד)
- האתר קורא רק מסמכים **שפורסמו**, דרך ה־CDN הציבורי. אין מפתח סודי בקוד או בדפדפן.
- אם Sanity לא זמין, איטי (יותר מ־4 שניות) או מחזיר שגיאה, האתר מציג את הרשימות מ־`brand.ts`. האתר אף פעם לא נשבר.
- אם לסוג מסוים אין עדיין שום מסמך, מוצגת הרשימה מ־`brand.ts` לאותו סוג. כדי להסתיר אזור לגמרי יש לרוקן אותו גם ב־`brand.ts`.
- כל פריט נבדק לפני הצגה (אורך, תאריך תקין, קישור https). פריט פגום מדולג.
- הצבעים של הממשק: `src/sanity/theme.ts`. השדות וההסברים בעברית: `src/sanity/schema.ts`.

## רענון מיידי (אופציונלי)
ב־sanity.io/manage → API → Webhooks: כתובת `https://<האתר>/api/revalidate`, שיטה POST,
כותרת `x-revalidate-secret` עם אותו ערך כמו המשתנה `SANITY_REVALIDATE_SECRET` ב־Netlify.

## לקוח חדש
משנים ב־`brand.ts` את `cms.projectId` (פרויקט Sanity חדש), מריצים את הזריעה מחדש או מזינים תוכן ב־`/studio`,
ומוסיפים את כתובת האתר ל־CORS של הפרויקט (sanity.io/manage → API → CORS origins, עם credentials).
