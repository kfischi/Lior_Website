# SEO report, 2026-10-26 (first run)

Run by hand in the build session, following `.claude/skills/organic-seo`.
Audited the code and a local production build only. The live site and Google
were not reachable from this environment, so **no ranking or traffic data**
is included, and none should be inferred.

## Status

`npm run typecheck`, `npm run lint` and `npm run build` pass. 12 pages and
routes are generated, including 3 new practice-area pages.

## Fixed this run (technical, no new claims)

| Finding | Fix |
| --- | --- |
| Without `SITE_URL`, canonicals, sitemap, robots and social previews pointed at `localhost` | `siteUrl()` now falls back to `brand.website` in production; only `next dev` uses localhost |
| Home `<title>` was only the firm name (30 chars) and did not mention the areas | Absolute title from `brand.seo.homeTitle` (49 chars), plus a 131-char description |
| Legal pages had no social preview image | Default `og:image` and Twitter image on every page |
| Sitemap `lastmod` changed on every build | Fixed date from `brand.seo.lastModified` |
| Sitemap, `llms.txt` did not list practice-area pages | Both list the three new pages |
| Structured data carried unconfirmed claims (`areaServed`, English) | Removed; kept only facts present in `brand.ts` |
| Header anchors (`#practice`, ...) broke on every sub-page | Now `/#practice` etc. |
| Legal page descriptions were 47-71 chars | Rewritten to about 100-120 chars |

## Added (needs the attorney's approval before going live)

Practice-area pages `/practice-areas/[slug]` for all three areas, each with a
unique H1, general explanation, "how we help", first steps, FAQ, breadcrumbs,
internal links to the other areas and a contact CTA. JSON-LD: Service,
FAQPage, BreadcrumbList. Home cards now link to the pages. All text is general
information stored in `brand.ts`; it contains no results, rankings or
comparisons, and no facts about the attorney beyond `brand.ts`.
